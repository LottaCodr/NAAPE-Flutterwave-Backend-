Authentication

Secure by default,
simple by design.

Protected routes use a signed JSON Web Token. Send the token returned by registration or login in the standard Authorization header.

Keep tokens private. Never place JWTs in source control, URLs, analytics events, or client-side logs.

Request header
Authorization: Bearer YOUR_JWT_TOKEN
Content-Type: application/json

Errors & recovery

Errors you can act on.

HTTP status codes carry meaning, while a stable response shape gives users a clear message and support teams a traceable request ID.

2xx
SuccessThe request completed as expected.
400
Invalid requestReview the message and submitted fields.
401
Authentication requiredSupply a valid, unexpired Bearer token.
403
Permission deniedThe account does not have the required role.
429
Rate limitedWait before retrying; inspect rate-limit headers.
